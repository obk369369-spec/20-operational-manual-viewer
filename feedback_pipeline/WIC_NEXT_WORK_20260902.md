- 테스트/수정 루프가 비정상적으로 길어짐

`반복비용 감지 → 기존 WIC PASS 자산 검색 → 외부 검증부품 후보 검토 필요성 판정 → 현재 방식 계속/재사용/구조전환 3안 비교 → 시간·크레딧 절감 가능성이 큰 대안을 사용자에게 선제 제안`
