# ChatGPT ↔ Claude 공통 작업 인계 계약 (2026-11-17)

## 목적
ChatGPT와 Claude Code/Cowork가 동일한 GitHub 저장소의 검증된 자료를 기준으로 작업을 이어받는다. 대화창 복사는 동기화 수단이 아니며, 자동 동기화·24시간 무인 실행이 검증되었다고 주장하지 않는다.

## 공통 원칙
1. 기존 자산·규칙·고객마스터·발송기록·안내서 레지스트리를 재사용하고 임의 재설계하지 않는다.
2. 작업 시작 전 저장소의 최신 커밋 및 대상별 원장/증거를 읽고, 이전 작업 완료 지점과 미완료·HOLD를 구분한다.
3. GitHub의 목록/메타데이터와 실제 ZIP/DOC/EML 원본은 별개다. 실제 원본 열기·해시·내용 확인이 되지 않으면 원본 확인 PASS로 표기하지 않는다.
4. 개인별 최신 재직·직함·연구분야는 공식 근거로 검증한다. 내부 2026년 안내서 우선, 발송 이력 중복 제거, 발행사 중복 방지, South Korea 중심 제목 제외. 없는 정보는 [원문 미기재].
5. 추정·임의 수치·임의 계산·임의 발송 금지. 승인 전 고객 메일 발송·운영 배포 금지.
6. 각 작업 완료 시 대상 ID, 입력 원본 경로와 버전, 변경 사항, 실행 증거, PASS/HOLD/FAIL, 남은 작업, 마지막 커밋 SHA를 GitHub에 기록한다. 커밋 성공만으로 E2E 완료를 선언하지 않는다.
7. 동시 작업 시 같은 파일을 무검증 덮어쓰지 않는다. 작업자별 브랜치 또는 독립 파일로 분리하고 충돌 확인 후 병합한다.
8. 서비스 사용 한도 도달 시 다른 서비스는 GitHub 마지막 검증 지점부터 재개한다. 대화 내용 자체는 자동 이전되지 않는다.
