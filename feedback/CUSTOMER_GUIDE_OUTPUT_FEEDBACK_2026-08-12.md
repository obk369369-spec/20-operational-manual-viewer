# CUSTOMER GUIDE OUTPUT FEEDBACK — 2026-08-12

상태: ACTIVE / CENTRAL FEEDBACK INTAKE
적용대상: 모든 고객 안내 대화창, 7번 고객 컨택 판단, 1번 고객 자동화 안내서, 고객용 보고서 추천/안내 출력

## 1. 고객용 출력은 일반 텍스트만
- 고객에게 붙여넣을 데이터는 일반 텍스트로만 출력한다.
- Markdown 강조기호 `**`, `*`, `###`, 코드블록 기호 등 ChatGPT/Markdown 흔적을 고객용 본문에 넣지 않는다.
- 보고서 정보에서 임의 굵은 글씨, 강조, 별표 표시를 만들지 않는다.
- 고객이 보았을 때 GPT에서 복사해 붙인 흔적이 남지 않게 한다.

## 2. 링크 정리
- 고객용 링크는 발행사 공식 상세페이지의 깨끗한 URL만 사용한다.
- `utm_source=chatgpt.com`을 포함한 모든 ChatGPT/검색 추적 파라미터를 제거한다.
- 특히 `?utm_source=chatgpt.com`, `&utm_source=chatgpt.com` 형태를 고객용 링크에서 절대 출력하지 않는다.
- Markdown 링크 문법 대신 필요 시 순수 공식 URL을 일반 텍스트로 출력한다.

## 3. 보고서 정보 처리
- 보고서 정보는 발행사 공식 보고서 페이지에 실제로 적혀 있는 내용만 사용한다.
- 사용자가 요구한 목적은 GPT의 분석문을 만드는 것이 아니라 공식페이지 내용을 고객이 읽을 수 있도록 한국어로 옮기는 것이다.
- 원문을 한국어로 번역만 한다.
- 임의 분석 금지.
- 임의 요약 금지.
- 여러 문장/여러 위치의 내용을 짜깁기하여 새 문장으로 재구성 금지.
- 고객 업무와 연결하는 해석문 추가 금지.
- 페이지에 없는 연결문장 추가 금지.
- 원문 의미·수치·순서가 바뀌지 않게 번역한다.
- 고객이 출처를 물으면 '발행사 공식 보고서 페이지 내용을 한국어로 옮긴 것'이라고 설명할 수 있어야 한다.

## 4. 목차 처리
- 기본 목차는 영문 원문 그대로 출력한다.
- 번역하지 않는다.
- 상위목차 + 하위목차까지만 출력한다.
- 하하위(3단계 이하) 목차는 기본 출력에서 제외한다.
- 하위목차는 상위목차보다 오른쪽으로 들여쓰기한다.
- 상위목차 0칸, 하위목차 2칸을 기본으로 한다.
- 원문 번호와 원문 순서를 유지한다.
- 목차가 공식페이지에서 확인되지 않는 보고서는 고객 추천자료에서 제외하고, 목차가 확인되는 다른 거래 발행사/보고서로 교체한다.
- 페이지 번호가 공개되지 않는 발행사는 허용한다.

## 5. 고객 안내서 붙여넣기 기본 순서
1. 영문 자료명
2. 한글 자료명
3. 발행사
4. 페이지
5. 가격
6. 발행일
7. 공식 링크
8. 목차 — 영문 상위+하위, 들여쓰기 유지
9. 보고서 정보 — 공식페이지 원문을 한국어로 번역만

## 6. 발행사/추천 조건
- 거래 가능 발행사 고정 풀 안에서만 추천한다.
- 한 고객의 3종 추천은 가능한 서로 다른 발행사로 분산한다.
- 목차 없는 보고서는 교체한다.
- 링크 없는 자료, 제목 불일치, 리디렉션, 비거래 발행사는 제외한다.

## 7. 대화창 이동 방지
- 사용자가 위 규칙을 다른 고객 안내 대화창에서 다시 설명하게 만들지 않는다.
- 관련 고객 안내/7번/1번 작업은 이 피드백을 중앙 공통규칙 승격 후보로 읽고 적용한다.
- 기존 중앙 규칙과 충돌 여부를 검사한 뒤 같은 의미는 병합하고, 최신 사용자 지시는 우선한다.
