# 16번 공통 ROOT — 대화창별 GitHub 기록 동기화 요구사항 (2026-11-05)

## 목적
사용자가 각 대화창에서 반복적으로 GitHub 업데이트를 지시하지 않아도, 모든 업무 대화창의 변경 내용을 해당 프로젝트 저장소와 공통 마스터에 자동 반영한다. ChatGPT 예약 크레딧 소모형 작업은 사용하지 않는다.

## 적용 범위
현재 및 향후 모든 업무 대화창. 기존 저장소·파일·커밋을 우선 재사용하며, 대화창별 프로젝트 ID/저장소 매핑과 공통 ROOT 연결을 유지한다. 민감한 개인자료(자동차보험, 가족, 건강, 개인식별정보 등)는 공개 저장소에 기록하지 않고 별도 접근 제한된 비공개 저장소에만 기록한다.

## 구현 및 검증 조건
1. 외부 완성형 자동화/실행 서비스를 우선 조사하고, 내부 개발·스크립트·신규 API 연동 금지라는 상위 제한을 준수한다.
2. 새 메시지·첨부·결정·검증상태의 변경분만 증분 반영한다. 중복 제거, 충돌 탐지, 원본 추적, 누락 재시도, 실패 알림을 요구한다.
3. 대화창 종료/작업 단위 완료 시 동기화를 우선하며, 가능한 경우 주기 동기화를 추가한다. 플랫폼이 제공하지 않는 전체 대화 기록 접근이나 무인 실행을 가능하다고 가정하지 않는다.
4. 외부 서비스의 실제 24시간 실행 가능 여부, 인증, GitHub 쓰기 권한, 비공개 경계, 재시작 지속성, 비용/크레딧을 검증한다. 무료·저비용의 기존 자산 우선, Render 휘발성 인스턴스 단독 의존 금지.
5. 검증은 대화창 2개 이상에서 변경→저장소 반영→중복 없이 재실행→누락 복구→재시작 후 지속성 확인까지 수행한다.
6. GitHub 커밋만으로 전체 동기화 완료를 선언하지 않는다. 완료/진행 중/HOLD/미실행을 분리해 기록한다.

## 현재 상태
- 공통 요구사항 문서 기록: 수행 대상
- 모든 과거 대화창 원문 일괄 추출: 미검증
- 전 대화창 자동 동기화: 미구축/미검증
- 개인 자동차보험 자료의 비공개 저장소 업로드: 별도 수행 필요
