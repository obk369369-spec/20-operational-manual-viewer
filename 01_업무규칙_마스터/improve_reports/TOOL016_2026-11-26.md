- 입력창 `<input type="text">` → `<textarea rows="2">`. 화면 문구("한 줄(또는 여러 줄 붙여넣기)")와 코드(`split(/\r?\n/)`)는 여러 줄 입력을 전제로 한다. 그런데 text input 은 붙여넣기 때 줄바꿈을 제거해서 여러 줄이 한 줄로 합쳐졌다.

- 이번 실행 확인: 복사본 HTML 은 여전히 변경 전(`<input type="text">`)이어서 위 3곳(태그·CSS·onkeydown)을 다시 적용했다.
- 참고: 이 작업 복사본에는 이전 실행의 노트만 있었고 실제 HTML 은 변경 전 상태였다. 그래서 변경을 다시 적용했다.
