## 외부 완성품 실무 성공 기준
1. 실제 외부 공급자의 공식 제품명과 제공처 확인
2. 기존에 진행하던 외부 제품의 마지막 작업 상태 우선 재개; 불필요한 처음부터 조사 금지
3. 정당하게 접근 가능한 계정/공식 체험 환경 연결
4. 실제 업무 입력 → 제품 내 실제 처리 → 결과 파일 회수 → 결과 검증
5. 위 증거가 없는 작업은 PASS 금지; '0건' 명시

## 공통 ROOT 및 크레딧 통제
- 오류는 작업 번호가 아닌 **동일한 근본 원인(ROOT)** 기준으로 중복 제거·통합한다.
- 공통 ROOT를 유지하되, 비용 큰 실행은 소단위로 제한한다. R1~R6 식 무제한 병렬 작업, 전체 저장소 반복 스캔, 동일 HOLD 재검증, 기록용 커밋만 반복하는 행위 금지.
- 서버 구축, Oracle/Deno/CircleCI 반복 실험, 자체 도구 복원은 외부 완성품 실제 도입과 무관하면 금지.
- 사용자 보고 시점의 Work 크레딧 잔량 **35%**. 추가 Work 실행은 중단하며, 사용자의 별도 승인 없이 Work 작업을 재개하지 않는다.
- 필요한 외부 서비스 로그인/권한은 한 번만 요청한다. 같은 조건 재시도 금지.
- 사용자가 같은 지시를 반복 설명하도록 요구하지 않는다.
