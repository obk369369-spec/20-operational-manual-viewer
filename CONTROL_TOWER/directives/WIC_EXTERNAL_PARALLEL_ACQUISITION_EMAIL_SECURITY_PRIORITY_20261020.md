# WIC 최상위 강제 지시 — 메일 보안 격리 및 외부 완성품 24시간 병렬 확보
작성일: 2026-10-20
범위: WIC 모든 사업/대화창/16번 Work/44번 Intake/Control Tower/외부 실행 장치

## 최상위 우선순위
1. 사용자 첨부 및 매일 수신 메일의 원본을 보존하고, 사기·피싱·보이스피싱 유도·사칭·악성 링크·악성 첨부 가능성을 우선 판별하여 사용자에게 근거와 함께 보고한다.
2. 악성 여부를 확인할 수 없는 경우 반드시 '미검증/격리'로 표시한다. 안전하다고 단정하지 않는다. SPF/DKIM/DMARC만으로 신뢰성을 보증하지 않는다.
3. 의심 메일/첨부/URL은 실행·클릭·외부 발송·사업 접촉에서 제외한다. 안전하게 추출된 비실행형 정보만 사업 기회 분석에 사용한다. 사용자 승인 없이 원본 메일을 영구 삭제하지 않는다. 격리와 영구 삭제를 구별하고, 원본 해시·격리 기록·복구 경로를 남긴다.
4. **최상위 실행 방식은 외부에서 이미 완성된 무료·상업 사용 가능·공유 가능한 제품/프로그램/도구/구조를 통째로 병렬 확보하여 실제 연결·검증하는 것**이다. 플랫폼 내부에서 새로 조합/개발하는 방식은 차선책이며 외부 완성품이 부족한 경우에만 허용한다.
5. 특정 Render 등 단일 호스팅 제품에 고정하거나 한 제품의 반복 수정으로 전체 작업을 지연하지 않는다. 대체 후보를 병렬 검증한다.

## 최대 공통 병렬 작업 묶음
A. Cafe24/IMAP 메일 자동 수집·원본 보존·중복 제거
B. 격리된 첨부 악성코드/URL/피싱 검사와 안전한 텍스트 추출
C. 업체·도메인·담당자·거래 실재 여부 독립 검증
D. WIC 기존 고객/보고서/발행사/거래 이력과 안전한 정보의 중복·기회 매칭
E. 외부 완성품 카탈로그·라이선스·무료 한도·상업/공유 조건 검증
F. 외부 조합 실행기·큐·재시도·오류 복구
G. 실제 사업 운영 기능(고객·협력사·견적·매칭·거래)
H. 독립 검증·감사 증거·사용자 관제 화면·16번/44번 ACK

서로 독립적인 A~H 확보·검증은 병렬 진행한다. 필수 의존성이 있는 실제 연결 단계만 순차 처리한다. 외부에서 24시간 자동 탐색하려면 실제 독립 실행 워커·스케줄러·운영 환경을 먼저 확보하고, 실제 가동 증거 없이 '24시간 운영'을 주장하지 않는다.

## 시작 차단
외부 완성품의 실제 연결·작동·독립 검증 증거가 없는 사업 운영/배포는 START_BLOCKED. 조사·후보 발굴·병렬 확보·격리 검사·검증 작업은 차단하지 않는다. 기존 PASS_LOCK/Evidence/Registry/Queue/Checkpoint 보존, 약 3200건 전수 재스캔 금지, 증분 처리.

## 검증과 보고
각 제품: 공식 출처/라이선스/무료 운영비/상업 공유 조건/실제 설치 및 실행 주소/연결 테스트/독립 검증 로그/원격 저장 commit 및 read-back.
각 메일: 원본 식별자·해시/발신자·회신 주소·도메인 불일치/인증 헤더/링크·첨부 격리 상태/검사 엔진·시각/판정 근거/사업 기회/사용자 알림.
상태는 CONFIRMED_MALICIOUS, HIGH_RISK_SUSPECTED, INCONCLUSIVE, LOW_RISK_VERIFIED로 구별한다. 검사되지 않은 파일을 안전으로 판정하지 않는다.
수익·완성·연결·배포·24시간 운영은 실증 없이 PASS 금지. 사용자에게 완료/미완료/차단 원인과 증거 URL을 간결하게 보고한다.

## 현재 증거 범위
이 파일을 GitHub에 저장하는 것은 지시문 저장 증거일 뿐이다. 외부 도구 확보, 배포, 24시간 가동, 실제 악성코드 검사, 메일 자동 삭제, 16번/44번 자동 인계의 증거로 간주하지 않는다.
