# WIC 고객 조사·보고서 매칭 절차 오류 및 강제 교정 (2026-10-13)

상태: RULE_RECORDED / IMPLEMENTATION_NOT_VERIFIED / RETROACTIVE_AUDIT_REQUIRED
적용 범위: 42번 고객 안내를 포함한 WIC 전체 고객조사·보고서 추천·메일 작성 경로 및 연결된 공통 거버넌스. 기존 PASS_LOCK과 증거를 무효화하거나 전체 재스캔하지 않는다.

## 사용자 지시의 정확한 의미
'고객 조사', '온라인 조사', '분야 조사', '자료 매칭'은 별도 축약 작업이 아니다. 고객의 **현재 재직 여부·직함·담당 업무·실제 연구 분야·관심 분야**를 공개 근거로 조사하고, 내부 과거 이력과 대조한 뒤, 해당 고객 개인의 분야에 적합한 **검증된** 최신 보고서를 매칭하라는 일괄 지시다. 과거 안내 분야는 실제 연구/구매 관심의 증거가 아니다.

## 발견된 실패
- 일부 추천은 현재 재직·전문 분야 확인 전 과거 발송 보고서 및 기관의 일반 사업 분야를 근거로 선정됨.
- 김동영: SWCNT 관련 공개 근거가 있었으나 개인별 매칭 근거·기관 중복 교차검증 불충분.
- 박영수: CNT/수소 관련 공개 근거가 있었지만 김동영과 유사한 두 보고서를 추천, 현재 직함 미확인.
- 이경석: 2024~2025 발송 이력에는 탄소섬유, 펠트, 수소저장, 이차전지, CNT, 스마트 카본, 활성탄. 공개 특허에 아세틸렌 블랙·도전성 카본블랙·전도성 분말·CNT 발열잉크·그래핀 센서 관련 단서가 확인되어 기존 안내 분야와 실제 전문 분야를 구분할 필요가 드러남. 2026 현재 재직·직함, 내부 안내서 보유, 기관 단위 중복 여부는 미검증. 외부 2026 보고서 추천을 내부 매칭 완료로 표시 금지.
- 메일 초안에 회사 서명을 누락하거나 분리 제공하여 사용자가 수동으로 재결합해야 했음.

## 필수 게이트 (범용)
1. 동일인 식별과 현재 소속/직함/재직 상태 확인: 공식 기관, 최신 논문·특허·사업 공고 등 날짜와 링크 기록; 불확실성 분리.
2. 실제 연구·담당·관심 분야 확인: 공식 프로젝트/논문/특허/발표/회신/문의 등 근거별 구분. 관심/구매 의사는 직접 확인 없으면 추정으로 표시.
3. 고객 개인 및 기관 전체의 과거 발송·문의·구매 이력 비교: 이미 발송한 제목·연도·발행사와 중복/유사성 분리.
4. WIC 내부 원본 안내서에서 실재 보고서 매칭, 발행사·연도·페이지·목차·가격·링크 확인; 없으면 외부 발행사 탐색 후 '외부 후보'로 구분.
5. 고객의 **개인별 확인된 분야**와 각 보고서 목차의 대응 근거, 추천 이유, 대안 및 미확인 사항 제시. 임의 제목·가격·페이지 생성 금지.
6. 필수 증거 미확보 시 FAIL-CLOSED: '추천 후보/미검증'으로 표시하고 완료·발송 가능 선언 금지.
7. 메일은 제목/받는 사람/본문/아래 회사 서명을 **한 번의 복사로 사용 가능**하게 합쳐 출력. 첨부를 실제 확인하지 않았다면 '첨부 완료'라고 주장하지 않음.
8. 실행 여부/저장 위치/커밋/검증 증거를 명시. GitHub 규칙 문서 저장은 코드·자동화 반영이나 전수 검증 PASS를 뜻하지 않음.
9. 기존 검증된 PASS 재사용, 증분 범위로 누락 고객 추천만 재감사. 사용자에게 과거 원본 재제출/수동 테스트 강요 금지.
